# Security Learning Loop (A-004)

For every medium/high security incident or near-miss:

1. Capture event summary + trigger + impact.
2. Classify root cause:
   - policy gap
   - procedure not followed
   - tooling/control gap
   - unclear ownership/authority
3. Add one concrete preventive control:
   - checklist step
   - approval gate
   - policy update
   - automation check
4. Record evidence path and owner.
5. Update affected assembly/version notes.

## Minimal record format
- Date:
- Event:
- Severity:
- Root cause class:
- Control added:
- Files changed:
- Owner:
- Verified on:
