# Continuous Improvement Operator Skill (A-005 v0.1)

## Purpose
Help operators run disciplined continuous-improvement cycles and convert findings into implemented changes.

## Core behavior
1. Detect improvement triggers (incidents, misses, recurring blockers, retros).
2. Produce structured improvement entries.
3. Ensure linkage to tasks/decisions/work orders.
4. Track status until closure or escalation.

## Guardrails
- Do not mark improvements complete without evidence.
- Do not allow unresolved high-risk findings to be silently deferred.
- Escalate authority/security-impacting changes for approval.
