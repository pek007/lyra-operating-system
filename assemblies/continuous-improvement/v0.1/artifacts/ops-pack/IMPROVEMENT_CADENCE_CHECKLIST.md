# Improvement Cadence Checklist (A-005)

## Weekly
- [ ] Review incidents, misses, and blocked work
- [ ] Capture top 1-3 improvements
- [ ] Assign owner and due date
- [ ] Link each improvement to task/decision/work-order

## Biweekly
- [ ] Check implementation progress of prior improvements
- [ ] Validate whether controls/process changes were applied
- [ ] Close or escalate overdue improvements

## Monthly
- [ ] Review recurring failure patterns
- [ ] Update policy/process docs where needed
- [ ] Remove obsolete controls
- [ ] Publish summary in decision/process log
