# Knowledge Compilation

Status: draft wiki page
Date: 2026-04-03
Domain: Capabilities

## Summary
Knowledge Compilation is a Lyra-level capability for converting raw source material into durable, source-traceable, queryable knowledge artifacts that improve future synthesis, decision support, and continuity.

It is not just storage, retrieval, or a note-taking pattern. It is a structured capability for ingesting, compiling, linking, synthesizing, linting, and reusing knowledge over time.

## Why it matters
Without knowledge compilation, Lyra repeatedly risks:
- rediscovering the same structure
- losing value in one-off chat outputs
- relying too heavily on transcript memory
- producing useful insights that never become reusable assets

Knowledge Compilation exists to make understanding compound.

## Core elements
- raw source ingestion
- compiled source summaries
- concept pages
- topic pages
- synthesis notes
- output artifacts
- lint/health-check discipline
- boundary from governed operational truth

## Relationship to the compiled wiki
Knowledge Compilation is the capability.
The compiled wiki is a major human-facing representation mode of that capability.

## Current implementation status
- formal capability package created in Control Panel docs
- first pilot instance exists for AI tools landscape research
- second pilot instance exists for prompt-injection security research
- capability has already produced a downstream Security capability artifact (Prompt Injection Defense)

## Important boundary
Knowledge Compilation does not replace canonical plans, priorities, risks, or governance/state surfaces. It supports them by creating reusable intelligence artifacts.
