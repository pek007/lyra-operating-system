# Lyra Wiki Templates and Rules

Status: draft
Date: 2026-04-03
Owner: Lyra

## Purpose
Define the first templates and growth rules for the Lyra wiki so it can grow coherently as a compiled wiki rather than becoming inconsistent note sprawl.

## Contents
- `WIKI_GROWTH_RULES.md`
- `CONCEPT_PAGE_TEMPLATE.md`
- `TOPIC_PAGE_TEMPLATE.md`
- `CAPABILITY_PAGE_TEMPLATE.md`
- `CONTROL_PATTERN_PAGE_TEMPLATE.md`

## Core principle
The Lyra wiki should be:
- source-traceable where relevant
- human-browseable
- internally linked
- concise but useful
- clearly separate from operational truth surfaces
