# FINOPS_LITE_POLICY.md

## Purpose
Lightweight spend governance for subscriptions and API usage.

## Principles
1. Start with smallest viable plan.
2. Track real usage before upgrading.
3. Tie each paid tool to a measurable business outcome.
4. Prefer reversible commitments.
5. Cancel quickly when ROI is weak.

## Decision Gates for Paid Tools
Adopt/keep a paid tool only if one is true:
- Saves >= 2–3 hours/month of high-value work
- Improves quality materially on critical outputs
- Reduces meaningful operational risk

## Monthly Review Checklist
- Current monthly spend by service
- Actual usage vs expected
- Outcomes achieved (time saved, quality uplift, risk reduction)
- Keep / downgrade / cancel decision
- Next review date
