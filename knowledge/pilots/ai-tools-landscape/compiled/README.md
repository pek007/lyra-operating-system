# Compiled Knowledge

Purpose: hold LLM-maintained, queryable markdown artifacts derived from the raw corpus.

## Artifact classes
- `sources/` — source summary pages
- `topics/` — topic pages
- `concepts/` — recurring concept pages
- `comparisons/` — comparative notes
- `syntheses/` — cross-source synthesis artifacts
- `indexes/` — browse and lookup surfaces

## Working rule
This layer may be updated by an LLM-assisted compilation workflow.
It should remain source-traceable and heavily linked.

## Important boundary
This layer does not replace canonical plans, decisions, priorities, risks, or governance artifacts.
