# Raw

Purpose: store minimally transformed source material for the AI Tools Landscape pilot.

## Principles
- preserve provenance
- avoid unnecessary rewriting
- keep source URLs / origin references where possible
- do not mix compiled summaries into this layer

## Suggested subfolders
- `external/` — web articles, papers, public research, repo notes
- `internal/` — internal notes, reflections, internal source material
- `images/` — downloaded images/figures/screenshots related to sources

## Naming guidance
Prefer descriptive stable names with date or source slug where practical.

Example:
- `2026-04-03__karpathy-llm-knowledge-bases.md`
