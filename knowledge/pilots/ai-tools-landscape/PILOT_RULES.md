# Pilot Rules

## Core rules
1. Keep `raw/` and `compiled/` distinct.
2. Preserve provenance wherever possible.
3. Let the LLM maintain the compiled layer by default.
4. Do not let the pilot silently rewrite governed operational truth.
5. File durable query outputs back into the pilot.
6. Prefer simple markdown-native conventions before heavier infrastructure.

## Pilot success test
This pilot is successful if it creates reusable knowledge artifacts that improve recurring research and synthesis quality.
It is not successful if it merely creates a larger pile of markdown.
