# Adopt Now vs Later — Community OpenClaw Ideas

## Adopt Now (OS-level)
1. Data classification tiers + handling rules
2. Outbound redaction/safety gate for sensitive content
3. Learnings/errors log for operational memory
4. Topic separation and notification batching discipline

## Defer (PX business automation lane)
1. CRM auto-stage updates
2. Meeting transcript action pipelines
3. Automated content-to-campaign pipelines
4. Financial NLQ stack and wearable ingestion

## Reasoning
Adopt-now items improve control-plane reliability/security with low implementation burden.
Deferred items are company automation projects and should be run as separate initiatives with business-case gating.
