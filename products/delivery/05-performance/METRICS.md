# Metrics

## North star
Capability moves from idea to safe accepted outcome with low friction and strong auditability.

## Throughput / flow
- lead time by work type
- cycle time by state
- WIP by lane/profile
- blocked age

## Quality / stability
- verification pass rate
- post-release issue rate
- change fail rate for software delivery units
- exception rate

## Governance / auditability
- % of delivery units with complete evidence packs
- % of transitions executed with policy validation
- approval latency
- % of rendered outputs generated from canonical state

## Learning
- % of closed delivery units with post-delivery review
- retro-to-policy conversion rate
- miss recurrence rate
