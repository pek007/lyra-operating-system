# Roadmap

## Horizon 1 — Estate clarity and posture honesty
- make the in-scope security estate across Lyra OS and `pxs` easy to inspect
- keep current posture, residual-risk framing, and trust-boundary assumptions explicit and internally consistent
- preserve a clear product-level baseline for current `pxs` security posture
- ensure material environment and integration changes trigger explicit Security review

## Horizon 2 — Upstream and ecosystem intelligence discipline
- establish a lightweight standing loop for OpenClaw release/security-impact monitoring
- establish a lightweight standing loop for ecosystem pattern intake and applicability assessment
- turn upstream and ecosystem findings into explicit actions, decisions, watch items, or deferred-risk notes

## Horizon 3 — Integration onboarding and traceability maturity
- define a repeatable Security review pattern for new platforms and services such as Google Workspace
- strengthen identity, sharing, and integration posture for new SaaS surfaces
- define higher-value auditability/logging/traceability expectations for material actions and control-relevant events

## Horizon 4 — More machine-checkable assurance
- automate selected control/evidence loops where they reduce ambiguity without creating excess noise
- strengthen posture verification for high-risk execution surfaces while preserving operational usability
- reduce dependence on narrative-only posture claims where deterministic checks are feasible

## Horizon 5 — Externalization readiness
- define what would be required for stronger packaging, tenant discipline, and broader customer applicability
- identify which current internal assumptions would break under more external or multi-tenant operating conditions
