# Governance

## Governance posture
Security operates with relatively high governance intensity because downside can be material, but it should still function as an enabling product rather than a blanket bottleneck.

## Core controls
- no silent trust-boundary, credential, access, or exposure changes
- explicit residual-risk decisions for material exceptions
- evidence-backed review cadence
- portfolio governance overrides product-local interpretation where authority conflicts arise

## Escalation triggers
Escalate to Peter for:
- material trust-boundary changes
- credential/access expansion
- significant unresolved risk acceptance
- broad cross-product security consequences

## Review model
- weekly security posture review
- event-driven review after significant changes or findings
- baseline refresh when deployment posture changes materially
