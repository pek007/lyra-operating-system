# Strategy

## Strategic objective
Create a trusted, low-overhead control and steering surface for Lyra OS operations and model stewardship.

## Strategic choices
1. Focus on visibility, governance, model stewardship, and safe control first.
2. Keep runtime and deployment boundaries explicit.
3. Avoid replacing product-specific execution tooling unless there is clear leverage.
4. Make Control Panel the operator-facing stewardship layer for the Lyra OS Model without collapsing all domain ownership into the product.
