# Interfaces

## Upstream interfaces
- governance and shared platform capabilities
- Lyra OS Model artifacts and their owning domain artifacts

## Downstream interfaces
- operator and product-owner control surfaces
- model stewardship and review surfaces

## Key boundary rule
Control Panel should not become a hidden dependency sink for product-specific logic or the sole home of all model-domain substance. It should remain the operator-facing control and stewardship layer over those structures.
