# Operating Model

Control Panel should evolve through small, evidence-backed improvements that increase operator visibility, steering quality, model coherence, and safe control without expanding scope into unrelated workflow ownership.

Control Panel is responsible for the operator-facing stewardship of the Lyra OS Model: observing model drift, surfacing model-change needs, supporting model review loops, and helping maintain coherence between explicit design authority and runtime/product/workspace reality.

Control Panel is not the sole owner of all underlying model-domain substance; detailed domain logic should remain with the most specific authoritative artifacts and products where appropriate.
