# Product Session Bootstrap Pack v1

Purpose: standardize one focused session/channel per product owner.

## Products (current)
- Control Panel
- Task Management
- Governance
- Security
- Improvement
- Delivery
- Interfaces

## How to use
1. Create/rename one Telegram topic/channel per product.
2. Create one OpenClaw session per product owner.
3. Seed the session with the corresponding `product-sessions/<product>/SESSION_STARTER.md`.
4. Keep cross-product requests in Interface tickets (not ad hoc chat drift).

## Required controls per product session
- Clear scope (`owns` / `does-not-own`)
- Active backlog and next 3 priorities
- Interface contracts with other products
- Cadence (weekly review + monthly boundary check)
- Evidence links for decisions and high-risk changes

## Session naming convention
`[Product] Owner — <name>`
Examples:
- `Task Management Owner — Lyra`
- `Security Owner — Lyra`
