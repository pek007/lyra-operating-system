# Lyra OpenClaw System Charter v1

Date: 2026-02-28
Owner: Peter/Lyra
Status: Active

## System mission
Build and operate an AI-native execution system that improves Peter's decision quality and delivery capability with high trust, low noise, and measurable compounding improvements.

## Not-for
- Feature output without validated decision value
- Persona proliferation without durable runtime boundaries
- Process ceremony that is not tied to measurable outcomes

## Strategic objectives (ranked)
1. **Decision value first**: improve real decisions and outcomes before UI or feature breadth.
2. **Execution reliability**: predictable, auditable delivery with explicit gates.
3. **Security and trust boundaries**: enforce least privilege and clear escalation.
4. **Cost-aware performance**: maximize value per token/time/cost.
5. **Compounding improvement**: retros and reviews must change behavior measurably.

## Operating principles
1. Jobs first, agents second, runtime third.
2. Start from the smallest viable execution surface (session/sub-agent before persistent agent).
3. Prefer decision artifacts before interface expansion.
4. Keep systems-of-record explicit; derived views must link to source truth.
5. Use hard config for hard boundaries; prose is guidance, not enforcement.
6. Keep always-injected context lean; store long analysis as reference docs.
7. Stop starting, start finishing (WIP discipline).

## Trade-off order
Guardrails > Objectives > Principles > Style

## 30-90 day focus
- Enforce project start packet and decision-first MVP gating
- Run job-market model for role assignments
- Harden release-delta adaptation and process compounding loops
