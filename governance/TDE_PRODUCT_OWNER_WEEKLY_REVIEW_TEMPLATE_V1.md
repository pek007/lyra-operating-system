# TDE Product Owner Weekly Review Template v1

Status: Active
Owner: Peter Eklind
Applies to: All Lyra OS product owners and product-like workstreams
Date: 2026-03-09

## Purpose
Provide a compact, repeatable weekly review format for checking whether a product/workstream is operating cleanly through TDE and whether execution is improving over time.

## How to use
Use this template at least weekly for each meaningful product/workstream.

Keep answers short, concrete, and evidence-based.
If an answer is weak or unclear, create or update the relevant TDE item rather than leaving the gap in prose.

## Minimum standard for a useful weekly review
A weekly review is only useful if it:
- links work to goals,
- distinguishes blockers from decisions,
- cites evidence instead of vague progress language,
- captures recurring friction as improvement work,
- and results in concrete TDE updates where needed.
